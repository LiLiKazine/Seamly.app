# Button

Small radius — a document, not a bubble. One filled button per screen.

```jsx
<Button variant="filled" size="large" onClick={next}>Looks right</Button>
```

## Props

| Prop | Type | Notes |
|---|---|---|
| `variant` | `"filled"|"tonal"|"outline"|"plain"|"danger"` | filled is the one primary action |
| `size` | `"small"|"medium"|"large"` | 44pt floor at medium |
| `symbol` | `string` | optional SF Symbol |
| `disabled` | `boolean` |  |
