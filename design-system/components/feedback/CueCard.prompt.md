# CueCard

The ONLY place the haptic buzz is taught. Nothing may be drawn during a broadcast, so meaning has to be carried before and after.

```jsx
<CueCard when="before" title="A buzz means slow down" body="…" />
```

## Props

| Prop | Type | Notes |
|---|---|---|
| `symbol` | `string` |  |
| `when` | `"before"|"after"` | before a session, or explaining it after |
| `title` | `string` |  |
| `body` | `string` |  |
