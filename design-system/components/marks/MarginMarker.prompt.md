# MarginMarker

The answer to the paper direction's weakness. Signal lives in the MARGIN, where the ground is always paper and contrast is guaranteed whatever was captured.

```jsx
<MarginMarker n={1} kind="flagged" atPct={38} onClick={jump} />
```

## Props

| Prop | Type | Notes |
|---|---|---|
| `n` | `number` | ties the mark to its row in the queue |
| `kind` | `"flagged"|"gap"|"confident"` |  |
| `atPct` | `number` |  |
| `selected` | `boolean` |  |
