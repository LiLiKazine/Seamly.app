# NavBar

Over a capture use over — a protection gradient, never a flat scrim.

```jsx
<NavBar title="Today" subtitle="884 × 15 402 px" over onBack={back} />
```

| `large` | `boolean` | large-title variant |
| `backLabel` | `string` |  |
