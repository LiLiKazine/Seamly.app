# Sheet

Slides up as paper: square top edge with a rule, small radius.

```jsx
<Sheet title="Export" trailing={<Button variant="plain">Done</Button>}>…</Sheet>
```

## Props

| Prop | Type | Notes |
|---|---|---|
| `title` | `string` |  |
| `leading` | `ReactNode` | usually Cancel |
| `trailing` | `ReactNode` | usually the confirming action |
