# Icon

Keyed by SF Symbol name so mocks and Swift name the same glyph. Inline paths — no CDN.

```jsx
<Icon name="flag" size={13} />
```

## Props

| Prop | Type | Notes |
|---|---|---|
| `name` | `string` | SF Symbol name the Swift source uses |
| `size` | `number` | px; tracks adjacent text size |
| `strokeWidth` | `number` | 1.6 default |
